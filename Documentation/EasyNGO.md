# EasyNGO

Simplifying Unity Netcode for GameObjects development.

EasyNGO is a utility package designed to make working with Unity Netcode for GameObjects (NGO) easier and more convenient.

The goal of EasyNGO is to provide reusable tools and helper functions that simplify common development tasks and help developers keep their projects clean and organized.

## Requirements

Before using EasyNGO, make sure your project meets the following requirements:

Unity 6 is recommended. EasyNGO has been tested with Unity 6.3 LTS.

Netcode for GameObjects (NGO)

Additional dependencies may be required depending on the features you use.
