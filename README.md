# EasyNGO

> **⚠️ Experimental / Prototype Phase**  
> *EasyNGO is currently in early development and experimental. APIs may change, and bugs are expected. Use with caution in production projects!*

**EasyNGO** is a Unity utility package designed to simplify and streamline working with **Netcode for GameObjects (NGO)**. If you want to speed up your multiplayer development and cut down on boilerplate code, EasyNGO is here to help.

---

## Features (Planned & Current)
* **Simplified Setup:** Reduces the boilerplate code usually required for NGO.
* **Quicker Networking:** Helps you spin up multiplayer systems faster.

## Installation

### Option 1: Unity Package Manager (Git URL)
1. Open your Unity Project.
2. Go to **Window** > **Package Manager**.
